# Contributing with a coding agent

Read README.md and the relevant source before editing. Keep the helper dependency
free on Python 3.10+. Source skills live in skills/, host differences in adapters/.
Validate with `python3 scripts/validate.py`.

Preserve user-owned config and files. Do not weaken a failed check or conflate
local evidence with live-host behavior. Add meaningful regression coverage for
filesystem, state or verification changes. Keep prompts original and short.
Publication, release and changes to unrelated projects follow the user's scope.
