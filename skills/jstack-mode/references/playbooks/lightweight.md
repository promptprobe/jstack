# Lightweight

Use for a narrow, reversible change whose effect can be checked directly: a typo,
spacing adjustment or label. Name the intended effect in one sentence, inspect the
smallest relevant slice, edit, and check the resulting artifact. Keep the task
contract brief. Do not create an architecture exercise or a review panel.

No child agents. Do not write tests that merely duplicate the edited value; use
an existing relevant check or inspect the rendered result. Project-required checks
still apply. If the work reveals behavior changes, data migration, authentication
or an uncertain boundary, change the playbook explicitly and explain the reason.
