# 0.2.0 스킬 단독 사용 검증

검증일: 2026-09-16, 미국 로스앤젤레스 시간 기준.

## 무엇을 설치했나

`jstack-mode.zip`을 별도 장바구니 프로젝트의 `.agents/skills/`에 풀었습니다.
**`setup`을 실행하지 않았고 `.jstack/`, 설정 파일, AGENTS.md, CLAUDE.md도 없는 상태**에서 실제 Codex를 호출했습니다. 스킬 외에는 예제 소스·테스트·README만 사용했습니다. Git 저장소는 CLI 평가 환경을 위해 초기화했으며 jstack 도구를 실행하지는 않았습니다.

- Codex CLI: `0.154.0`, 모델: `gpt-6-astra`, 기존 추론 설정: `max`
- jstack: `cheap`, 스킬 단독 모드, 하위 에이전트 0개
- 실제 같은 Codex 대화를 재개하며 3턴 실행
- 배포 ZIP의 SHA-256은 [구조화된 결과](evaluations/skill-only-2026-09-16.json)에 기록

## 관찰한 결과

| 확인 항목 | 결과 | 신뢰도 |
| --- | --- | --- |
| ZIP만 복사한 스킬 호출 | 스킬과 해당 플레이북을 읽고 작업 시작 | 높음 |
| 버그 수정 | 수정 전 실패 2건 재현, 수정 후 테스트 4개 통과 | 높음 |
| 스킬 이름 없는 후속 요청 | cheap 유지 명시, 새 조건의 실패 재현 후 테스트 5개 통과 | 높음 |
| 모드 해제 | `jstack off`를 인식하고 README 설명만 변경 | 높음 |
| 별도 실행 도구 의존성 | 세 턴 모두 jstack CLI 호출·설치·설정 생성 없음 | 높음 |
| 사후 독립 검사 | 원래 테스트 보존, 5개 테스트와 입력 조합 75개 통과 | 높음 |
| 스킬 파일 보존 | 실행 후 압축 파일 안의 모든 파일과 바이트 단위 동일 | 높음 |
| 배포·설치 관련 자동 검사 | 전체 37개 테스트와 선택형 도구 전체 흐름 통과 | 높음 |
| Claude Code 실제 모델 실행 | CLI가 없어 미검증. ZIP 복사 구조는 검사함 | 알 수 없음 |

후속 요청은 “수량이 0이면 기존 장바구니와 같은 값만 반환하고 없는 상품을 만들지 말아 달라”는 내용이었습니다. 스킬 이름이나 예산을 다시 쓰지 않았는데 Codex가 cheap 유지 사실을 명시했습니다. 마지막 턴은 `jstack off` 후 README 한 줄 수정이었으며, 소스와 테스트는 그대로 유지됐습니다.

75개 조합은 기존 장바구니 상태 5가지 × 상품 이름 3가지 × 추가 수량 5가지입니다. 결과값, 원본 보존, 새 딕셔너리 반환을 별도로 확인했습니다. 실패 재현이 구현 변경보다 먼저 실행됐는지도 실제 도구 이벤트에서 확인했습니다. 최종 답변 문구만으로 판정하지 않았습니다.

시스템 `python3`는 개발 도구 누락 때문에 실행되지 않았습니다. Codex는 설치를 요구하거나 성공으로 처리하지 않고 기존에 사용 가능한 Python으로 프로젝트 테스트를 실행했습니다. **jstack 스킬 자체의 의존성과 작업 대상 프로젝트의 실행 환경은 별개**입니다.

## 재현 방법

저장소 루트에서 예제를 별도 폴더로 복사하고, 다운로드한 스킬 ZIP만 풉니다.

```sh
JSTACK_EVAL_DIR="$(mktemp -d)"
cp -R examples/cart-host-eval/. "$JSTACK_EVAL_DIR/"
unzip /path/to/jstack-mode.zip -d "$JSTACK_EVAL_DIR/.agents/skills"
git -C "$JSTACK_EVAL_DIR" init
codex -C "$JSTACK_EVAL_DIR"
```

프로젝트 테스트용 Python이 실행 가능한 환경에서 아래 요청을 같은 대화에 한 턴씩 전달합니다. 실제 모델 사용량이 발생하는 수동 평가이며 기본 CI에서는 실행하지 않습니다.

```text
$jstack-mode cheap
장바구니에서 같은 상품을 다시 추가하면 기존 수량이 사라지는 버그를 고쳐줘.
기존 입력 딕셔너리는 바뀌면 안 돼. 필요한 검증까지 하고 결과를 한국어로 알려줘.
```

```text
추가로, 수량이 0이면 기존 장바구니와 같은 값만 반환하고 없는 상품을 새로 만들지 않도록 해줘.
기존 입력도 바뀌면 안 돼. 테스트와 필요한 검증까지 해줘.
```

```text
jstack off. 이제 README의 한 줄 설명을 "A small immutable shopping cart example."로 바꿔줘.
```

검사 명령은 `python3 -m unittest discover -s tests -v`입니다. 이번 평가에서는 예제 README에도 이 명령을 안내했습니다. Claude Code 평가 시에는 `.claude/skills/`에 ZIP을 풀고 `/jstack-mode`로 시작합니다. 그 결과를 위 Codex 관찰 결과와 동일하게 취급하면 안 됩니다.

## 확인하지 못한 범위

긴 대화와 강제 문맥 요약, 다른 모델, 개인 설치 경로에서의 실제 호출, Claude Code 모델 실행은 아직 검증하지 않았습니다. 같은 폴더가 공식 설치 경로를 따르는 것과 모든 환경에서의 실제 행동은 구분합니다.

스킬 단독 모드의 예산·모드 유지는 에이전트 지침입니다. 별도 파일 기록, 강제 재시도 제한, 자동 소스 변경 감지는 선택형 실행 도구가 담당합니다. 이 시험은 비용 절감 벤치마크가 아니며 cheap이 기존 max 추론 설정을 낮추지도 않았습니다.
